Entry for the make.fun bounty **"Unsent: The Micro-Confession Sprint"** — one two-part micro-confession: a `To:` line naming who the message was meant for, and the unsent message itself, one line written exactly as it was typed, with no explanation after it.

The confession was chosen by duel-testing seven drafts pairwise against the judge's brief (specific and honest, a felt reason it stayed in drafts, To: line and message needing each other, reading as typed and never sent). The winner: a kept voicemail, a name said wrong three times, and a correction that will never be sent — too late, too honest, and only ever meant for one person.

## Running

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), with a self-check that the text is 1–260 characters, UTF-8, and exactly two parts.
